# MOVIS capstone defense preparation

This release improves the existing system and supplies an evidence-based defense
kit. It does not certify research results or successful phone installation.
The overall project is **not yet ready for a final evaluated capstone defense**:
warehouse item classes, tested YOLO weights, actual-device verification and user
evaluation are missing. The software is conditionally ready for a clearly labeled
demonstration after the updated source is deployed and the hosted checks pass.

Read these files in order:
1. REQUIREMENTS.md — actual document content versus template instructions.
2. AUDIT.md — problems, effects, fixes, checks and remaining limitations.
3. ARCHITECTURE.md — implemented architecture, database and algorithms.
4. DEPLOYMENT.md — exact source uploads, Render settings, model placement and rollback.
5. USER-GUIDE.md — roles, workflows and troubleshooting.
6. DEMONSTRATION.md — repeatable defense demonstration and panel questions.
7. EVALUATION.md — test evidence, measurable research plan and acceptance gates.

The phone photographs items; the server runs inference; the website monitors
inventory and histories. Both clients use one database. The user's computer can
be switched off after cloud deployment; internet and working hosting are required.
Website photo capture was explicitly excluded by the user and remains absent.

Changes in this release are local. Public health/website access was checked on
2026-10-03 and the hosted server reported demo mode. New authenticated features
have not been deployed or exercised against the user's production account.
Never present synthetic detections as model accuracy or successful training.

The files under defense are supporting material, not a replacement for a finished
institution-approved manuscript. Adviser review, actual warehouse permission and
ethically collected evaluation data remain the student's responsibility.
