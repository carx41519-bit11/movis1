# New image workflow

Choose an action before capture. The in-app rear camera has no gallery import or zoom controls. The Captured Images panel beside Add more images contains this action's new images. Enlarge, check, delete and retake as needed. Raw model results and checked rice quantities remain separate.

Deleted images never contribute to totals, including a late detection response. Save scan preserves checked quantities without stock changes. Final submission recalculates kept-image totals on the server and locks accepted evidence. Request and image IDs preserve unchanged outcomes on retry.

Stock-in adds checked quantities; stock-out subtracts only if every selected product has enough stock. Inventory Count retains starting balances and versions, stores comparisons on Finish count, and changes stock only through a separate authorized adjustment. Physically confirm complete coverage and any zero result. Additional manual checked quantities require reasons and must not duplicate photographed sacks.
